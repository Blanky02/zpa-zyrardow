v2 AUTO – jak to działa?

Aplikacja przy starcie robi fetch('./timetables.json?v=timestamp'). Jeśli scraper (Python) w nocy wykryje nowy PDF na stronie PKS/ZPA, nadpisuje timetables.json. Użytkownik od razu widzi nową wersję + baner "Nowy rozkład". Fallback: localStorage cache + dane demo w pliku.

📲 PWA na Android - zainstalowana OFFLINE

Zainstaluj z banera u góry lub menu Chrome ⋮ > Zainstaluj aplikację. Działa offline dzięki Service Worker (sw.js). Cache'uje index.html + timetables.json + ikony + Tailwind. Tryb: network-first dla rozkładu, cache-first dla shella.

📦 Pliki PWA: manifest.json + sw.js + icons/ 🔄 Scraper: GitHub Actions codziennie 04:00 UTC 📍 Źródło: pksgostynin.pl + zpa.powiat-zyrardowski.pl
